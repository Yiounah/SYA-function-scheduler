## Foundation

macOS 桌面窗口。视觉身份见 `DESIGN.md`。数据仍走 FocusFlow 本地 HTTP：`/`, `/health`, `/api/v1/tasks/*`, `/ws/tree`。

## Information Architecture

| 表面 | 内容 |
| --- | --- |
| 进入规划 | 先确认午饭、晚饭、每天工时、工作时段和课题粒度。作息不合法时不能进入。 |
| 侧栏 | 新建规划；日 / 周 / 月；我的课题。点课题只切换，不打开修改。 |
| 顶栏 | 产品名「任务规划」；搜索；工作时间；今日粒度。 |
| 课题头 | 标题、按内容自动标注的标签、周期、整体进度，以及「修改规划」。 |
| 每日 | 当天叶子和钟点。确认更细草案后，未开始清单拆成同级小步；确认更粗草案后，同组未开始步骤合并并保留来源。 |
| 周 | 研究周报：与本周相交的阶段。 |
| 月 | 点某一天进入每日视图。 |
| 子任务卡 | 选中阶段的子任务，以及选中子任务的清单。 |

树映射：root = 课题；`root.children` = 里程碑；里程碑 children 或自身 = 子任务；子任务 children 或自身叶子 = 清单项。

## Voice and Tone

短、具体、研究场景。「开始规划」改为「生成时间轴」。「还没有路线图」改为「还没有课题」。

## Component Patterns

- 新建规划：目标、期限、课题粒度。等待拆解时显示生成进度与取消。成功后展示树、时间块和警告；确认才写入。模型失败保留输入并提供重试，示例规划明确标识。
- 修改规划：只重拆当前课题里尚未开始的分支。
- 点击阶段只改变选择。点击叶子子任务标为进行中。清单勾选在 `DONE` 与 `PENDING` 之间切换。
- 工作时间：先展示新时段与受影响任务；确认后按新作息重排，不改任务正文。取消和保存失败均保留原计划。
- 今日粒度：用户选择任务与粒度，或从 Monitor 带任务/原因进入；预览剩余步骤后确认。已完成及执行中的节点不被重拆。
- 目标分钟：更细 5–30、标准 25–60、更粗 45–120，显示调整前后清单数量、总分钟和来源变化；无需调整时禁用确认。分段是时间组织，不虚构新的任务目标。
- 作息节拍：显示生效日期、工作起止、连续专注、短休息、周期恢复，预览可用窗口与净产能的区别。日历区分工作和休息，休息没有完成任务操作。
- 保存进度：重新拉取树并提示已同步。

## State Patterns

- 空：无树。时间轴与子任务显示空态，引导新建规划。
- 规划中：中央条纹进度，禁止重复提交，可以取消等待；迟到的结果不自动应用。
- 作息建议：至少两次在可工作时间之外处理任务后弹出。接受则改工时和时段；拒绝则记住这次建议，避免立刻再弹。
- 今日粒度建议：受阻或超时建议更细；顺利完成且无积压建议更宽。翻页和搜索不重新弹出。
- 有树：默认选中第一个进行中或未完成里程碑。
- 搜索无结果：子任务列显示「没有匹配的任务」。

## Interaction Primitives

单击选择；复选框切换完成；Escape 关闭模态。无拖拽改期。

## Accessibility Floor

搜索框有 label；模态有标题；时间轴节点有 button 语义；toast 使用 `aria-live=polite`。

## Key Flows

1. 林打开应用，先确认作息，再新建一个课题，并可以再追加另一个课题。
2. 高潮：在当天清单里勾选下一步，进度上升；若连续在设定时段之外工作，系统建议调整作息，由林决定。
3. 若今天的步骤过点仍未完成，系统建议把今天拆细；林可以拒绝，正式计划保持不变；确认时服务检查草案版本，若进度已改变则提示重新预览。
